# Обычный рабочий лист: 1–4 классы

**Статус всех педагогических положений:** методическая рекомендация.

## Общие правила

- Прочитать `design-system.md` и выбрать профиль по классу.
- Прочитать `bloom-taxonomy.md`. Не использовать A/B/C. Определить навыки Блума по точному действию цели, назначению листа и возрасту. Не просить учителя выбирать их обязательно; явно переданные навыки принять только после проверки достижимости.
- Не применять обязательную балльную шкалу. В руководстве учителя давать наблюдаемые признаки выполнения и пример корректирующей реплики.
- Считать лист средством обучения и практики, а не формой суммативного оценивания. По умолчанию не добавлять баллы, проценты, итоговую отметку, БЖБ/ТЖБ или официальную рубрику.
- Использовать короткие инструкции, один смысловой блок за раз и показ нового действия.
- В каждом задании разнести метку, инструкцию и рабочий материал на отдельные визуальные уровни по `design-system.md`. Инструкция не должна конкурировать с тем, что ребёнок читает, выбирает, соединяет, обводит или записывает.
- Не размещать заголовок следующего задания сразу под таблицей, рамкой, строкой ответа или последней строкой предыдущего задания. Между самостоятельными заданиями оставлять отдельный видимый белый промежуток по `design-system.md`; при нехватке места переносить целый блок или сокращать объём, а не убирать этот интервал.
- После каждого задания выводить краткий возрастно понятный дескриптор наблюдаемого действия. Не перегружать задание 2–4 формальными дескрипторами: использовать минимальное количество, достаточное для проверки выполнения.
- Создавать один общий лист со встроенными опорами и заданием на углубление. Отдельные варианты делать только по прямой просьбе учителя.
- Сохранять одну общую цель: поддержка уменьшает барьер выполнения, а углубление усиливает рассуждение, но не подменяет цель.
- Подбирать разделы по назначению листа; не включать все возможные разделы автоматически.

## 1 класс

- Предпочитать выбор, соединение, обведение, раскрашивание с учебной функцией, указание, рисунок, предметное действие и короткий устный ответ.
- Письмо использовать только в объёме, необходимом цели.
- Дать один визуальный пример и нумерованные шаги с пиктограммой-дублёром.
- Инструкцию размещать короткой строкой над рабочим материалом. Слово, предложение, число, изображение или поле, с которым ребёнок работает, показывать заметно крупнее и выделять спокойной цветной плашкой или рамкой. Различие должно сохраняться и при чёрно-белой печати.
- Самопроверка: один-два понятных признака без баллов и публичного ранжирования.
- Ученическая часть обычно 1 страница; вторая допустима только по реальной необходимости.

## 2 класс

- Сочетать совместный образец и короткую самостоятельную практику.
- Использовать 2–4 задания, но считать учебные действия, а не мелкие подпункты.
- Самопроверка по одному-двум признакам: «орындадым / тексеремін» или локализованный эквивалент.
- Ученическая часть не более 2 страниц.

## 3 класс

- Использовать сравнение, короткое объяснение способа и применение в знакомой ситуации.
- Допускать таблицы, простые данные и задания с выбором стратегии при понятном образце.
- Использовать 3–5 заданий, только если объём оправдан целью и временем.
- Оставлять достаточно места для короткого объяснения; не приравнивать сложность мышления к объёму письма.

## 4 класс

- Допускать самостоятельный отбор информации, аргументацию выбора, объяснение стратегии и применение в новой, но доступной ситуации.
- Использовать таблицы, диаграммы, короткие источники и мини-исследование только когда они прямо служат цели.
- Использовать 3–5 заданий, если объём оправдан целью и временем.
- Короткие ученические критерии допустимы; формальные полные дескрипторы оставить руководству учителя.

## Рекомендуемая композиция

В зависимости от назначения выбрать необходимые элементы: имя и дата; понятный ученику ориентир; короткая актуализация; образец; 2–4 основных учебных действия; встроенная опора; углубление; итоговое доказательство; действенная самопроверка. Не добавлять декоративное задание, повторяющее уже полученное доказательство.

## Раздел для учителя

Для каждого задания показать: навык Блума, ожидаемый результат, допустимые способы ответа, один-два наблюдаемых признака, типичную ошибку, конкретную корректирующую реплику и доступную опору. В конце добавить краткую таблицу `Тапсырма / Задание | Блум | Оқу мақсатымен байланысы / Связь с целью` и указать следующий учебный шаг по результату диагностики. Для 1–4 классов баллы добавлять только по прямой просьбе учителя, не связывать автоматически с итоговой отметкой и маркировать как методическую рекомендацию.
