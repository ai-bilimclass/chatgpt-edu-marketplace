# КТЖ / КТП

1. Полностью прочитать [рабочий протокол](runtime-workflow.md).
2. Использовать только подтверждённую программу, точные цели и параметры расписания.
3. Собрать и проверить редактируемый КТЖ/КТП по правилам выбранной ступени.
4. После результата предложить следующий подходящий учебный материал.
