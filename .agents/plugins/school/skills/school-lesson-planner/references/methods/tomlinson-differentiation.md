## Педагогическая задача

**Авторское основание:** заранее учитывать различия в готовности, интересе и учебном профиле, гибко меняя содержание, процесс, продукт или среду. Модель решает проблему одной траектории для неоднородного класса при сохранении содержательной ценности работы.

Не предназначена для создания отдельной цели каждому ученику или постоянного деления на уровни способностей.

## Когда выбирать

- данные показывают разные уровни предыдущего знания;
- части класса нужна опора, а готовым ученикам — глубина;
- языковой или организационный барьер мешает показать предметное действие;
- одинаковый темп или ресурс ограничивает доступ;
- требуется гибкая группировка по конкретной потребности.

## Перевод в действия

1. Учитель определяет общий неизменный результат и критерий.
2. По доказательствам уточняет барьер, не назначая ярлык ученику.
3. Создаёт путь с поддержкой, основной путь и при необходимости углублённый перенос.
4. Ученик выполняет одну цель с разной опорой; группы меняются по текущим данным.
5. Опора постепенно снимается.

Пример: при общей цели построить аргумент путь с поддержкой получает отобранные доказательства и речевые начала; основной — набор источников; углублённый — противоречивые источники и требование оценить надёжность. Критерий аргумента общий.

## Проверка результата

Сравнивать варианты по одной оцениваемой конструкции. Полный результат — самостоятельное достижение критерия; частичный — достижение с конкретной опорой; слабый — барьер остаётся. Решение: снять опору, изменить её тип или восстановить предыдущее знание.

## Когда недостаточно

Не использовать без данных, не считать интерес или «стиль» постоянным свойством и не заменять углубление большим объёмом. Для проектирования доступности всего класса дополнить UDL; для сбора данных — Wiliam; для явного освоения предпосылки — Archer–Hughes.

## Адаптация для Казахстана

**Қазақстандық бейімдеу:** сохранять точную цель программы и ступенчатые правила оценивания. Поддерживать язык обучения и предметный язык, не снижая содержание. Не ставить диагноз; учитывать решения учителя, инклюзивную среду и офлайн-ресурсы.

## Индикаторы качества

- адаптация основана на конкретном барьере;
- цель и существенный критерий общие;
- каждый вариант содержательно уважителен;
- группы гибкие;
- готовые ученики получают глубину, а не объём;
- поддержка ведёт к самостоятельности.

## Типичные ошибки

- постоянные группы «слабые/сильные»;
- лёгкая цель для части класса без основания;
- больше упражнений вместо углубления;
- ярлык «учебного стиля»;
- разные продукты, измеряющие разные цели.

## Связи

UDL проектирует доступность заранее для всего класса, Wiliam даёт данные для адаптации, Archer–Hughes — временную явную опору. Функция Tomlinson — гибкая реакция на различия готовности и потребности.
