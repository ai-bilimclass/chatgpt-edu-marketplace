# Visible Learning (көрінетін оқыту / видимое обучение) — John Hattie

**Архитектурный статус:** доказательное основание для прозрачности цели, прогресса и следующего шага; не отдельный вариант выбора в методическом роутере и не синоним Visible Thinking.

## Педагогическая задача

**Авторское основание:** сделать обучение видимым учителю и ученику: понятны цель, текущее положение и следующий шаг, а учитель оценивает влияние преподавания по изменениям в работе учеников.

Не предназначена для механического рейтинга стратегий или обещания конкретному классу результата по средней величине эффекта.

## Когда выбирать

- ученики выполняют действия, но не понимают цель и качество;
- критерий формально показан, но не используется;
- обратная связь не отвечает «что дальше»;
- учитель оценивает урок по активности, а не по изменению результата;
- нужно сделать прогресс и саморегуляцию наблюдаемыми.

## Перевод в действия

1. Учитель переводит цель урока в понятный, но не упрощённый язык.
2. Показывает или совместно анализирует признаки качественной работы.
3. Ученик сравнивает свой результат с критерием и называет следующий шаг.
4. Учитель ищет доказательство собственного влияния и корректирует решение.
5. Ученик улучшает работу после обратной связи.

Пример: перед написанием объяснения класс сравнивает два коротких образца по критерию; после первого ответа каждый отмечает подтверждённый признак и одну доработку, затем переписывает фрагмент.

## Проверка результата

Доказательства: ученик объясняет цель своими словами, распознаёт качество, точно определяет текущий пробел и выполняет следующий шаг. При частичном понимании уточнить критерий на примерах; при неверной самооценке сопоставить с работой; при полном результате повысить самостоятельность.

## Когда недостаточно

Ясная цель сама по себе не обучает новой процедуре и не обеспечивает доступность. Дополнить Archer–Hughes для явного обучения, Wiliam для широкого сбора доказательств, UbD для согласования итогового результата. Не использовать effect size без контекста как приказ выбрать метод.

## Адаптация для Казахстана

**Қазақстандық бейімдеу:** ученическая формулировка не заменяет официальный код и текст цели. Условные шкалы прогресса не заменяют нормативное оценивание. Эмоциональная рефлексия дополняет, но не заменяет доказательство обучения.

## Индикаторы качества

- ученик понимает цель и признаки результата;
- текущий уровень определяется по работе;
- обратная связь содержит выполнимый следующий шаг;
- ученик действует после неё;
- учитель меняет решение по доказательству;
- итог отражает изменение обучения.

## Типичные ошибки

- эффект как гарантированный рейтинг;
- чтение цели без её понимания;
- общая похвала вместо информации;
- чрезмерное количество комментариев без времени на исправление;
- замена предметной методики общими принципами.

## Связи

Wiliam конкретизирует формативный цикл, UbD — итоговое доказательство, Marzano — систему стратегий. Функция Visible Learning — прозрачность цели, прогресса и следующего шага для обеих сторон.
