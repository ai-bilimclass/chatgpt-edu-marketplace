# Project Based Learning — PBL (жобаға негізделген оқыту / проектное обучение)

**Статус:** специализированное направление; применять только при подтверждённых условиях.

Выбирать, когда цель допускает протяжённую работу над значимым вопросом и создание продукта для определённого адресата. Требуются достаточное время, этапы, доступные ресурсы, критерии качества, промежуточная обратная связь и индивидуальное доказательство вклада каждого ученика.

Не называть проектом краткую поделку, презентацию после обычного задания или распределение ролей без исследования и пересмотра продукта. Основная последовательность: вопрос → необходимые знания → план → создание → проверка по критериям → улучшение → представление → индивидуальная рефлексия. Если условия не выполнены, использовать обычное проблемное или практическое задание внутри основного направления.
