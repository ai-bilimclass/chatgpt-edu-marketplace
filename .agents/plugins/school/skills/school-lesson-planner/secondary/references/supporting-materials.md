# Дополнительные материалы к уроку

## Когда использовать

Использовать, если учитель просит полный комплект урока или отдельный материал.

## Доступные материалы

- рабочий лист ученика;
- карточки для дифференциации;
- формативное оценивание;
- рубрика оценивания;
- дескрипторы;
- домашнее задание трех уровней;
- материалы и адаптации для учащихся с ООП;
- список надежных внешних ресурсов;
- методические рекомендации для учителя.

## Требования

Каждый материал должен:

- быть связан с целями урока и критериями оценивания;
- соответствовать возрасту и языку обучения;
- содержать понятную инструкцию;
- поддерживать самостоятельную интеллектуальную работу учащегося;
- иметь ответы, ключ или ориентиры для учителя, если это необходимо;
- предусматривать доступную офлайн-альтернативу цифровому или платному ресурсу;
- не дублировать основное задание без педагогической причины.

## Дифференциация

Проектировать не просто три объема одной работы, а разные уровни поддержки и когнитивной сложности:

- **поддержка**: образец, алгоритм, визуальная или языковая опора;
- **основной уровень**: самостоятельное достижение общей цели;
- **углубление**: перенос, аргументация, исследование, создание или оценка.

## Материалы для учащихся с ООП

Не ставить диагнозы и не снижать цель автоматически. Предлагать:

- упрощенную формулировку инструкции без упрощения содержания;
- визуальные и пошаговые опоры;
- альтернативный способ ответа;
- дополнительное время;
- уменьшение лишней нагрузки;
- доступный формат материалов;
- рекомендации по поддержке без стигматизации.

## Упаковка

- Небольшие материалы включать после методического приложения в основной DOCX.
- Объемные рабочие листы, комплекты карточек, рубрики и отдельные материалы для печати создавать отдельными DOCX-файлами.
- При запросе «полный комплект урока» сначала создать КСП, затем все необходимые материалы без повторного согласования каждого элемента.
