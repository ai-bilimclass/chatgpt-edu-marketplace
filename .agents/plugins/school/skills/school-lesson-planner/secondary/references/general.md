# Общая межпредметная методика

Использовать этот файл только для предмета, не охваченного другими справочниками, или для универсальной межпредметной задачи без явно ведущей дисциплины.

## Проектирование

- Определить основной наблюдаемый результат и продукт учащегося.
- Выстроить задания от актуализации к освоению, применению, обратной связи и рефлексии.
- Сделать связь между целью, заданием, доказательством и оцениванием явной.
- Обеспечить основную интеллектуальную работу учащихся, а не педагога.
- Использовать реальные и доступные ресурсы; предусмотреть нецифровую альтернативу.

## Точность и оценивание

- Проверить факты, термины, инструкции, ответы и источники.
- Разделять знания, навыки, отношение и продукт; не оценивать их одним неясным критерием.
- Формулировать наблюдаемые дескрипторы без слов «понимает» и «знает», если проявление результата не указано.
- Поддержку строить через ясность инструкции, образец, визуальную опору, последовательность или выбор формата ответа.
- Углубление строить через перенос, аргументацию, исследование, создание или оценку.

Если по ходу работы предмет становится очевиден, прекратить использование общего файла и прочитать соответствующий предметный справочник до разработки содержания.
