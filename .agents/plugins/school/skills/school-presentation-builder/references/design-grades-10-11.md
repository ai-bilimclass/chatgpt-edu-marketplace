# Дизайн для 10–11 классов

- Использовать строгую аналитическую композицию с акцентом на доказательства и данные.
- Ориентироваться на 50–90 слов только для действительно аналитического слайда.
- Допускать более компактную компоновку, сохраняя проекторную читаемость.
- Применять содержательные графики, цитаты и источники; уменьшать декоративность.
- Не имитировать университетский слайд с мелким шрифтом и плотным абзацем.

| Роль | Целевой размер |
|---|---:|
| Заголовок слайда | 35–36 pt |
| Ключевая фраза/вопрос | 24–30 pt |
| Основной текст/инструкция | 20–26 pt |
| Таблица/диаграмма | 18–22 pt |
| Подпись | 16–19 pt |
| Источник | 13–16 pt |

Терминологию визуально отделять от пояснений. Усложнение строить через перенос,
синтез, оценку доказательств или альтернативную интерпретацию.
