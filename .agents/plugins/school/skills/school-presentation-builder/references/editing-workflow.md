# Редактирование существующего PPTX

## До изменения

1. Сохранить исходный файл неизменённым и работать с копией результата.
2. Отрендерить все слайды и создать контактный лист.
3. Инспектировать `slide,textbox,shape,image,table,chart,notes,layout`.
4. Определить мастер, макет и локальные элементы каждого изменяемого слайда.
5. Зафиксировать перечень целевых слайдов, элементов и ожидаемых изменений.

## Во время изменения

- Править локальный элемент для единичной замены, макет — для повторяющегося блока,
  мастер — только для намеренного глобального изменения.
- Сохранять стабильные идентификаторы, заметки, ссылки, анимацию и комментарии,
  если пользователь не просил удалить их.
- Не перестраивать неизменяемые слайды и не смешивать исходный шаблон с новой темой.
- Для содержательных правок сверять цели, задания и оценивание с КСП/ҚМЖ.

## После изменения

1. Повторно инспектировать изменённые элементы.
2. Отрендерить изменённые слайды до/после и затем весь файл.
3. Проверить мастер → макет → слайд, нумерацию, логотипы и заметки.
4. Запустить проверки шрифтов, структуры, переполнения и открытия.
