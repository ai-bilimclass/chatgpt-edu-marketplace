## Правила выбора

- Запрос «сделай материалы к уроку» неоднозначен: уточнить продукт, не запускать сразу несколько генераторов.
- Если учитель последовательно заказывает связанные продукты, повторно использовать подтверждённые предмет, класс, язык, тему, цели и ограничения.
- Презентация и рабочий лист создаются только по готовому ҚМЖ/КСП: прикреплённому либо автоматически подготовленному после успешного создания и проверки в текущем чате.
- При запросе нескольких продуктов выполнять их по зависимости: КТП при необходимости → ҚМЖ/КСП → рабочий лист или оценивание → презентация. Перед каждым следующим продуктом использовать подтверждённый результат предыдущего этапа.
- После успешного создания и передачи каждого нового учебного материала обязательно запускать неизменяемый локализованный выбор по [общему правилу](../../../references/next-material-follow-up.md). Показывать полное меню из шести пунктов только на языке текущего запроса; не исключать завершённый вид и не считать консультацию или проверку созданием материала.
