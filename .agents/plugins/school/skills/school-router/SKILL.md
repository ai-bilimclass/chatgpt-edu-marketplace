# Маршрутизация школьных материалов

1. Полностью прочитать [рабочий протокол](runtime-workflow.md) и при первом обращении после подключения применить локализованное [стартовое сообщение](../../references/plugin-welcome.md).
2. Определить требуемый учебный материал и подтвердить существенные исходные данные.
3. Передать запрос соответствующему навыку, сохранив подтверждённый контекст.
4. Не создавать документ внутри маршрутизатора и не придумывать отсутствующие учебные цели.
