# Единый интерактивный раунд вопросов

Если для создания материала нужны несколько пользовательских решений, собрать их в один объединённый интерактивный раунд. При доступности активных кнопок использовать их для 2–3 взаимоисключающих вариантов каждого вопроса; при недоступности задать те же вопросы одним обычным сообщением.

Ответ учителя на интерактивный раунд считается окончательным выбором по всем показанным полям и достаточным разрешением продолжить создание материала. После получения ответов:

- не просить написать `келісемін`, `согласен`, `подтверждаю`, `confirm` или аналогичную фразу;
- не повторять уже отвеченные вопросы обычным текстом;
- не предлагать ещё один промежуточный план параметров только для подтверждения;
- кратко зафиксировать выбор и сразу перейти к созданию результата.

Если время, объём, количество страниц или количество заданий не были обязательным пользовательским решением и остались неуказанными, выбрать безопасное возрастное значение, явно назвать допущение и продолжить без нового вопроса. Например: `Тапсырмалар саны көрсетілмегендіктен, 8-сыныпқа қауіпсіз көлем ретінде 5 тапсырма және шамамен 28 минуттық жұмыс қабылданды. Жұмыс парағын құрастыруды бастаймын.`

Дополнительный вопрос после интерактивного раунда допустим только при обнаруженной позднее критической неоднозначности, без которой нельзя получить корректный результат: противоречащие друг другу планы разных классов или предметов, отсутствие точной обязательной учебной цели, обязательной спецификации либо сведений по безопасности реальной практической/лабораторной работы. Такой вопрос задавать один раз и объяснить конкретную причину. Обычный выбор количества заданий, времени, страниц, макета или рекомендуемого уровня сложности критической неоднозначностью не считать.

Кратковременное служебное состояние интерфейса после нажатия кнопки не трактовать как необходимость повторить вопрос. Ориентироваться на полученные ответы и продолжать работу.
