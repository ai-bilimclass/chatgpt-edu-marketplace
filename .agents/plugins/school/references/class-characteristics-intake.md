# Особенности класса для ҚМЖ/КСП

При создании нового ҚМЖ/КСП для 1–11 классов обязательно получить обезличенное описание особенностей класса, влияющих на учебный процесс. Для КТП этот вопрос не задавать.

Если сведения уже явно предоставлены в текущем чате и относятся к тому же классу и предмету, повторно их не спрашивать. Учитель всегда может выбрать один из предложенных вариантов, указать отсутствие особенностей или описать класс своими словами.

Точная казахская формулировка:

`Сыныптың оқу үдерісіне әсер ететін қандай ерекшеліктері бар?`

Русская формулировка:

`Какие особенности класса влияют на учебный процесс?`

English formulation:

`What class characteristics affect the learning process?`

После вопроса предложить краткие, методически содержательные варианты, адаптированные к классу, предмету, возрасту, языку обучения и характеру урока. Варианты должны описывать реальные педагогические решения: требуемую опору, темп, языковую поддержку, доступность, способ демонстрации понимания, потребность в усложнении или ресурсное ограничение. Не выдавать варианты за факты и не ограничиваться одинаковыми универсальными формулировками для всех предметов.

Последним вариантом всегда разрешить: `Ерекшелік жоқ / Особенностей нет / No relevant characteristics`, а после меню явно разрешить собственное описание учителя.
