# Ustaz BilimAI Mektep

Готовая версия плагина для размещения в GitHub и импорта в ChatGPT Edu.

- Версия: `0.1.10+codex.20260902093159`
- Внутреннее имя плагина: `school`
- Отображаемое название: `Ustaz BilimAI Mektep`
- Количество навыков: 6

Для загрузки на GitHub поместите в корень репозитория всё содержимое этой папки, включая скрытую папку `.agents`.

После загрузки администратор ChatGPT Edu импортирует URL репозитория через **Администрирование → Плагины → Добавить → Импортировать маркетплейс**. Поле пути оставляется пустым, если `.agents` находится в корне репозитория.
