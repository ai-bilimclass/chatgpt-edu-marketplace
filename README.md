# Ustaz BilimAI Mektep

Готовая версия плагина для размещения в GitHub и импорта в ChatGPT Edu.

- Версия: `0.1.22+codex.20260904092429`
- Внутреннее имя плагина: `school`
- Отображаемое название: `Ustaz BilimAI Mektep`
- Количество навыков: 6

## Изменения версии 0.1.22

- Отредактировано приглашение к опросу на казахском, русском и английском языках с сохранением единого смысла.
- Текст приглашения и локализованная ссылка на опрос выводятся жирным курсивом.
- В одном ответе показывается только языковая версия, соответствующая текущему запросу.

## Изменения версии 0.1.21

- Циклический вопрос о следующем материале заменён на более естественную и академически корректную формулировку.
- Казахская версия использует слово `құрастыру`: `Келесі кезекте қандай оқу материалын құрастыруды қалайсыз?`.
- Русская и английская версии сохраняют тот же смысл добровольного выбора учителя.

## Изменения версии 0.1.20

- Ответы на один объединённый интерактивный раунд считаются достаточными для немедленного продолжения создания материала.
- После активных кнопок запрещено повторно просить `келісемін`, `согласен`, `подтверждаю` или `confirm`.
- Для неуказанных обычных параметров рабочего листа применяется явно сообщаемое безопасное возрастное допущение без второго подтверждения.
- Дополнительный вопрос разрешён только при критической неоднозначности источников, цели, спецификации или безопасности.

## Изменения версии 0.1.19

- После первого готового ҚМЖ/КСП показывается одноразовое трёхъязычное уведомление: связанные материалы для одного класса и предмета рекомендуется создавать в одном чате.
- Уведомление не требует согласия и не блокирует дальнейшую работу; новый материал автоматически использует последний подходящий проверенный план текущего чата.
- Для нового чата явно требуется повторно прикрепить план. При наличии нескольких планов разных классов, предметов или тем плагин уточняет основу одним вопросом.
- Плагин не называет контекст текущего чата постоянной памятью.

## Изменения версии 0.1.18

- После успешного создания и проверки ҚМЖ/КСП последний план автоматически используется как основа для следующих материалов в текущем чате.
- Удалено обязательное требование писать `ҚМЖ-ны қабылдаймын`, `КСП принимаю` или другую подтверждающую фразу.
- После выдачи плана показывается только неблокирующее примечание. Учитель может указать другой план; в новом чате потребуется прикрепить нужный файл.

## Изменения версии 0.1.17

- В первичный опрос КТП добавлен вопрос №6 об особенностях класса, влияющих на обучение.
- После вопроса показываются ровно три варианта, адаптированные к предмету, классу и языку запроса.
- Ответ сохраняется и передаётся в последующие учебные материалы без повторного запроса.

## Изменения версии 0.1.16

- Вопрос о днях занятий перенесён в число первых обязательных вопросов любого запроса на КТП.
- Вопрос больше не зависит от недельной нагрузки и не предполагает конкретное количество дней.
- Формулировки: `Аптаның қай күндерінде/күнінде сабақ өтеді?`, `В какие дни/какой день недели проходят уроки?`, `On which day/days of the week are the lessons held?`.

## Изменения версии 0.1.15

- Учебный год КТП фиксируется как `2026–2027` и больше не запрашивается у учителя.
- Вопрос о днях занятий обязателен и формируется по недельной нагрузке; для трёх часов используется вопрос `Аптаның қай үш күнінде сабақ өтеді?`.
- Правило синхронизировано в маршрутизаторе, режимах 1–4 и 5–11 классов и входных схемах генераторов.

## Изменения версии 0.1.14

- В маршрутизатор добавлен одноразовый трёхъязычный опрос после четвёртого успешно созданного материала в текущем чате.
- Показ опроса ограничен периодом до 3 октября 2026 года включительно.
- Счётчик не включает ошибки, незавершённые работы, маршрутизацию и проверки без создания нового материала.

## Изменения версии 0.1.13

- рабочие листы и презентации создаются на основе прикреплённого или утверждённого в текущем чате ҚМЖ/КСП/Lesson Plan;
- каждое задание рабочего листа получает локализованный дескриптор;
- в презентациях используются `Бағалау критерийлері`, `Критерии оценивания` и `Assessment criteria`;
- в письменных инструкциях ФО/СОР/СОЧ установлено требование использовать синюю пасту;
- обновлены названия рекомендаций учителю по организации оценивания;
- добавлено трёхъязычное объяснение модерации суммативного оценивания.
- термин `Success Criteria / Жетістік критерийлері / Критерии успеха` заменён на `Assessment Criteria / Бағалау критерийлері / Критерии оценивания`;
- методическое ядро ҚМЖ/КСП дополнено расширенным перечнем глаголов-действий для шести уровней таксономии Блума.
- после каждого созданного материала задаётся локализованный вопрос о следующем материале; завершённый вид исключается из предлагаемых вариантов, а подтверждённый контекст сохраняется.
- методология ҚМЖ/КСП централизована по архитектуре `6 основных направлений + 3 специализированных направления + инструменты и доказательные основания`;
- методический маршрутизатор автоматически выбирает основной метод по цели, этапу обучения, затруднению и контексту, не требуя от учителя выбирать автора или концепцию;
- подтверждённое методическое решение передаётся через `lesson_plan_handoff` в рабочий лист, оценивание и презентацию без повторного выбора и дублирования методологии.
- для Kagan Structures добавлена обязательная проверка PIES: положительная взаимозависимость, индивидуальная ответственность, равное участие и одновременное взаимодействие;
- в маршрутизатор добавлена таблица границ PBL, Design Thinking и Inquiry-/Problem-based Learning;
- протокол проектирования дополнен 15-шаговым интеграционным циклом от нормативной проверки до рефлексии учителя;
- аудит расширен проверками метапознания, закрепления и переноса, ресурсного равенства, цифровой безопасности, конфиденциальности, авторства и академической честности.
- видимый `SKILL.md` каждого из шести навыков сокращён до компактного маршрутизатора; полный рабочий протокол вынесен в обязательный `runtime-workflow.md`, а детальная методология сохранена в `references/` без изменения функциональных алгоритмов.

Для загрузки на GitHub поместите в корень репозитория всё содержимое этой папки, включая скрытую папку `.agents`.

После загрузки администратор ChatGPT Edu импортирует URL репозитория через **Администрирование → Плагины → Добавить → Импортировать маркетплейс**. Поле пути оставляется пустым, если `.agents` находится в корне репозитория.
