# Шаблон результата

Собрать разделы ниже в один PDF. Начать версию для учителя с новой страницы. В чате не дублировать содержание PDF.

## 1. Статус и допущения

- `Статус: готово по предоставленной спецификации` или `Проект для проверки/модерации`.
- Перечислить только существенные допущения: время, распределение Блума, недостающие цели; максимальный балл — для промежуточного оценивания, СОР/СОЧ.

Если запрос на СОЧ остановлен из-за предметного исключения или нагрузки 1 час в неделю, файл оценочной работы не создавать. В чате вывести основание ограничения и предложить допустимую альтернативу.

## 2. Паспорт оценивания

Для 1 класса пропустить паспорт и матрицу. Использовать сокращённую структуру рабочего листа: заголовок, тема, шапка, точная цель обучения, задания, критерии, дескрипторы, ключ/пример ответа и строка «Основание» без баллов. Обратную связь добавлять только по запросу.

| Параметр | Значение |

| Вид оценивания | |

| Период выставления итоговой оценки | Четверть или полугодие |
| Цели обучения | |
| Уровни Блума | |

## 3. Матрица

Для ФО использовать таблицу без баллов:

| № | Цель обучения | Критерий | Блум | Формат | Время |
|---|---|---|---|---|---:|

Для промежуточного оценивания, СОР/СОЧ использовать таблицу с баллами:

| № | Цель обучения | Критерий | Блум | Формат | Балл | Время |
|---|---|---|---|---|---:|---:|

Для промежуточного оценивания, СОР/СОЧ после таблицы подтвердить сумму баллов и времени. Для ФО подтвердить количество заданий и время; во 2–4 классах отдельно указать общую шкалу 1–10 без распределения баллов по заданиям.
В столбце `Формат` использовать локализованные названия из [task-formats.md](task-formats.md): альтернативный выбор, выбор одного ответа, выбор нескольких ответов, опознание, дополнение, краткий ответ, соответствие или последовательность.

## 4. Материал для обучающегося

Оформить как рабочий лист по [worksheet-structure.md](worksheet-structure.md):

1. Локализованный заголовок рабочего листа и номер.
2. Тема урока.
3. Шапка с предметом, классом, Ф. И. О. и датой.
4. Код и точная формулировка цели обучения.
5. Общая инструкция и допустимые материалы.
6. Нумерованные задания и отдельные области ответа. После каждого задания добавлять краткие дескрипторы, кроме СОЧ; в СОЧ дескрипторы не включать.
7. Для 1 класса и ФО – блок самооценки; для остальных видов только по запросу или спецификации.

Балл указывать только для промежуточного оценивания, СОР/СОЧ. В ФО и заданиях 1 класса не ставить баллы рядом с заданиями. Включить все источники, изображения, таблицы и формулы, необходимые для ответа.

## 5. Материал для учителя

Начать с новой страницы и оформить как руководство к рабочему листу по [worksheet-structure.md](worksheet-structure.md). После локализованного предупреждения и основной информации дать отдельный блок для каждого задания: название, правильный/возможный ответ и, когда применимо, полные дескрипторы и баллы. Для СОЧ дескрипторы не добавлять; использовать ожидаемые элементы ответа и условия начисления баллов.

Для ФО использовать таблицу только с дескрипторами:

| № | Критерий оценивания | Дескриптор/наблюдаемое действие |
|---|---|---|

Для промежуточного оценивания и СОР использовать таблицу со схемой баллов:

| № | Критерий оценивания | Дескриптор/ожидаемый элемент | Балл |
|---|---|---|---:|

Для СОЧ использовать таблицу без дескрипторов:

| № | Критерий оценивания | Ожидаемый элемент ответа | Балл |
|---|---|---|---:|

Затем дать ключ ответов. Для открытых ответов привести образец и правило принятия эквивалентных ответов. Для аналитической рубрики описать уровни отдельно по каждому критерию.

В конце версии для учителя добавить раздел `Рекомендации учителю по проведению оценивания` по [teacher-guidance.md](teacher-guidance.md). Указать уровень подробности; при отсутствии значения использовать уровень учителя-стажёра.

После порядка проведения добавить подраздел `На что обратить внимание при проверке работы`. Для каждого задания указать проверяемый элемент, допустимые эквивалентные ответы, независимое начисление баллов, типичные ошибки, запрет двойного снижения и пример предметной обратной связи.

## 6. Обратная связь

Для ФО:

- `Цель:` что обучающийся должен уметь.
- `Уже получается:` конкретное свидетельство.
- `Следующий шаг:` одно выполнимое действие.

Для СОР при необходимости дать рубрику по целям обучения без сравнения детей между собой.

## 7. Проверка качества

Кратко отметить:

- покрытие целей: `x/x`;
- количество заданий: план/факт;
- для СОЧ — соответствие количества, форматов, времени, баллов и структуры предоставленной спецификации либо явно подтверждённым проектным допущениям;
- для промежуточного оценивания, СОР/СОЧ — сумма баллов: матрица/рубрика;
- для ФО 2–4 классов — шкала 1–10 и отсутствие баллов у отдельных заданий/дескрипторов;
- для ФО 5–11 классов — отсутствие баллов, процентов и отметок;
- для 1 класса — наличие дескрипторов и отсутствие баллов, шкалы, процентов и отметки;
- для 1–4 классов — ссылка на инструктивно-методическое письмо;
- распределение Блума;
- соответствие форматов заданий целям и инструкциям;
- возрастная и языковая доступность;
- нормативные параметры: подтверждены источником или оставлены как проектные.
- руководство учителю написано на языке документа, соответствует уровню опыта и содержит конкретные действия;
- терминология соответствует [terminology.md](terminology.md), близкие процедуры не смешаны.
