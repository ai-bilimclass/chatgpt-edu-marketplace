# Структура рабочего листа

Использовать эту структуру для версии обучающегося и следующего за ней руководства учителю. Содержание, количество заданий, баллы и объём определяются веткой оценивания из `SKILL.md`; пример рабочего листа не переопределяет нормативные правила.

## 1. Версия обучающегося

Размещать элементы в следующем порядке:

1. Заголовок по языку документа: `ЖҰМЫС ПАРАҒЫ №___` для `kk`, `РАБОЧИЙ ЛИСТ №___` для `ru` или `ASSESSMENT SHEET №___` для `en`. Если номер извлечён из КТП, ҚМЖ/КСП или `worksheet_handoff`, подставить его; иначе сохранить `№___`.
2. Тема урока отдельной строкой.
3. Шапка-таблица: предмет, класс, Ф. И. О. обучающегося, дата. Все подписи локализовать и не смешивать языки.
4. Точная цель обучения: код и официальная формулировка без перефразирования.
5. Нумерованные задания в количестве, выбранном пользователем. Не заменять это количество фиксированным диапазоном из примера.
6. После каждого задания – краткие наблюдаемые дескрипторы, которые не раскрывают правильный ответ, кроме СОЧ. В СОЧ по умолчанию дескрипторы не размещать; если утверждённая спецификация прямо требует их, сохранить её структуру. Для промежуточного оценивания, СОР и СОЧ показывать балл только в соответствии со спецификацией; для 1 класса и ФО балл рядом с заданием не показывать.
7. Для учебных заданий 1 класса и ФО – блок самооценки из 2–4 утверждений с флажком `☐`. Для промежуточного оценивания, СОР и СОЧ добавлять самооценку только по запросу или если она предусмотрена шаблоном пользователя.

Структура каждого задания:

Обычная ветка: `Задание N. Название` → инструкция → стимульный материал при необходимости → отдельная область ответа → `Дескрипторы`.

СОЧ: `Задание N. Название` → инструкция → стимульный материал при необходимости → отдельная область ответа. Блок `Дескрипторы` не добавлять, если спецификация не требует иного.

- Формулировать 2–4 коротких дескриптора как измеримые действия в третьем лице: `определяет`, `сопоставляет`, `различает`, `классифицирует`, `описывает`, `сравнивает`, `объясняет`, `обосновывает`, `делает вывод`; для `kk` использовать естественные казахские эквиваленты.
- Не использовать отдельные дескрипторы `знает` или `понимает` без наблюдаемого действия.
- Если задание разделено на подпункты, дать отдельную область ответа для каждого подпункта.
- Использовать изображение только когда без него нельзя проверить цель обучения. Не оставлять текстовый заполнитель изображения в готовом документе: вставить доступное изображение либо перестроить задание без него.
- Стремиться уместить обычный рабочий лист или ФО в две страницы A4. Для СОР/СОЧ и работ со спецификацией объём определяет содержание и заданное время; не уменьшать шрифт ради искусственного ограничения.

## 2. Руководство учителю

Начинать с новой страницы. Заголовок: `Жұмыс парағына арналған нұсқаулық` для `kk` или `Руководство к рабочему листу` для `ru`.

В начале разместить светло-серый блок без отдельного заголовка:

- `kk`: `Төмендегі жауап кілті мен толық дескрипторлар тек мұғалімге арналған. Оқушыларға көрсетілмейді және таратылмайды.`
- `ru`: `Приведённые ниже ключ ответов и полные дескрипторы предназначены только для учителя. Материал не показывается и не раздаётся обучающимся.`

Если материал предусматривает баллы, дополнить сообщение словами о схеме баллов. Не упоминать баллы для 1 класса и ФО 5–11 классов.

Затем один раз указать предмет, класс, тему, цель обучения и критерий оценивания. Для каждого задания создать отдельный визуальный блок в таком порядке:

1. `Задание N. Название`.
2. Правильный или возможный ответ.
3. Полные дескрипторы; для СОЧ этот пункт пропустить и вместо него указать ожидаемые элементы ответа.
4. Баллы – только для промежуточного оценивания, СОР и СОЧ. Для ФО 2–4 классов вместо поэлементных баллов после всех заданий показать общую шкалу 1–10 и правило совокупного оценивания.

Для открытого ответа добавлять: `Принимаются иные ответы, верные по смыслу` или естественный казахский эквивалент.

После блоков заданий:

- для промежуточного оценивания, СОР и СОЧ – итоговая таблица `Задание | Балл` и проверенная сумма;
- для ФО 2–4 классов – общая шкала 1–10 без распределения баллов по заданиям;
- для 1 класса и ФО 5–11 классов – без таблицы баллов;
- дать формирующую обратную связь по модели `цель → текущий результат → следующий шаг`, когда она требуется веткой оценивания.
- добавить `Рекомендации учителю по проведению оценивания` по [teacher-guidance.md](teacher-guidance.md): подготовка, инструктаж, допустимая помощь, запрещённые подсказки, адаптации, завершение, проверка и обратная связь.

## 3. Макет

- Формат страницы A4, белый фон, чёрный текст, без декоративных элементов.
- Основной шрифт – Times New Roman 13 pt; заголовки – 13 pt полужирным. Если пользователь предоставил обязательный шаблон, сохранить его шрифт и стили.
- Таблицы и смысловые блоки оформлять тонкой серой или чёрной рамкой 0,5–0,75 pt; для шапок и учительского блока допустима заливка `F2F2F2`.
- Основной текст выравнивать по ширине; заголовок документа и тему – по центру.
- Длинные линии ответа создавать нижней границей абзаца, а не цепочкой символов подчёркивания. Между соседними линиями использовать абзац без границы, чтобы линии не сливались.
- Ширины таблиц и столбцов фиксировать в пределах рабочей ширины страницы. После рендеринга проверить, что подписи шапки не переносятся без необходимости и ни один столбец не выглядит непропорционально пустым.
- Руководство учителю начинать с новой страницы. В нижнем колонтитуле использовать простую нумерацию `1`, `2`, `3` без английских слов.

## 4. Проверка макета

Перед выдачей файла отрендерить его и визуально проверить каждую страницу:

- заголовок, номер, тема и шапка присутствуют;
- все подписи и весь текст на одном выбранном языке;
- каждое задание связано с целью и имеет собственную область ответа;
- у каждого подпункта есть отдельная область ответа;
- дескрипторы видимы обучающемуся, но не раскрывают ключ; для СОЧ структура следует спецификации, а в проекте без спецификации отдельный блок дескрипторов отсутствует;
- учительская часть начинается с новой страницы и содержит ответы и полные дескрипторы; для СОЧ по умолчанию вместо дескрипторов содержит ожидаемые элементы ответа и условия начисления баллов;
- количество, форматы, время и баллы СОЧ соответствуют спецификации либо подтверждённому проектному решению;
- баллы показаны только в разрешённой ветке и суммы совпадают;
- линии, таблицы и текст не обрезаны, не выходят за поля и не перекрываются.
- руководство учителю написано на языке документа и содержит отдельные точки проверки фактических заданий;
- термины ФО, промежуточного оценивания, СОР/СОЧ и аттестации используются по [terminology.md](terminology.md).
