# Матрица маршрутизации

Использовать только строку выбранного продукта. Все точные цели сохранять в формулировке учителя или приложенного им источника.

| Запрос учителя | Профильный навык | Блокирующие условия до запуска | Что уточняет профильный навык |
|---|---|---|---|
| КТП/среднесрочный план | `school-medium-term-plan` | Класс, предмет, язык результата. Для 5–11 классов — загруженная учебная программа. Для 1–4 классов — программа либо полный набор точных целей по четвертям вместе со сквозными темами. Для 1 класса по Әліппе/Букварю — предоставленные учителем разделы и темы уроков. | Нагрузка, соответствующее ей количество недельных уроковых дней, вариант программы/направление и календарные параметры, если их ещё нет. Учебный год автоматически фиксируется как `2026–2027` и не запрашивается. Предлагаемые для 1–4 классов названия уроков сначала показывает учителю для подтверждения. |

## Правила выбора

- Запрос «сделай материалы к уроку» неоднозначен: уточнить продукт, не запускать сразу несколько генераторов.
- Если учитель последовательно заказывает связанные продукты, повторно использовать подтверждённые предмет, класс, язык, тему, цели и ограничения.
- Презентация и рабочий лист создаются только по готовому ҚМЖ/КСП: прикреплённому либо автоматически подготовленному после успешного создания и проверки в текущем чате.
- При запросе нескольких продуктов выполнять их по зависимости: КТП при необходимости → ҚМЖ/КСП → рабочий лист или оценивание → презентация. Перед каждым следующим продуктом использовать подтверждённый результат предыдущего этапа.
- После успешного создания и передачи каждого учебного материала обязательно запускать циклический выбор следующего материала по [общему правилу](../../../references/next-material-follow-up.md). Задать локализованный вопрос `Келесі кезекте қандай оқу материалын құрастыруды қалайсыз?` / `Какой учебный материал вы хотели бы подготовить следующим?` / `Which learning material would you like to prepare next?` и показать доступные варианты, исключив только что завершённый вид материала. Например, после КТП не показывать КТП среди вариантов. Сохранить подтверждённый контекст и соблюдать зависимости: выбор рабочего листа или презентации без готового ҚМЖ/КСП сначала маршрутизировать к созданию или загрузке ҚМЖ/КСП.
