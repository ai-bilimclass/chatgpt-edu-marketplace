# Жұмыс парағы / Рабочий лист

1. Полностью прочитать [рабочий протокол](runtime-workflow.md).
2. Использовать подтверждённый ҚМЖ/КСП и переданный методологический контекст.
3. Создать задания, дескрипторы, ключи и необходимые правила безопасности.
4. Перед выдачей проверить перенос ID и дескрипторов скриптом `../../scripts/validate_derivative_alignment.py` для `artifact_type: worksheet`.
5. Проверить редактируемый результат и предложить следующий материал.

Обязательно применять [дескрипторы с баллами и оформление видов работы](../../references/scored-descriptors.md) для всех классов.
