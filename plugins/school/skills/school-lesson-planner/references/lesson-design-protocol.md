# Протокол проектирования урока

**Статус: методическая рекомендация.** Протокол не заменяет учебную программу, нормативную форму КСП или решение учителя.

## Исходные данные

До проектирования определить: предмет, класс, язык обучения, раздел или сквозную тему, тему урока, точный код и формулировку цели обучения, длительность, известные особенности класса, предыдущее обучение, подтверждённые потребности в поддержке и доступные ресурсы. Для химии, биологии, физики, естествознания / жаратылыстану и художественного труда / көркем еңбек отдельно подтвердить возможность практической работы и недоступные средства. Неизвестные сведения не придумывать. Запрашивать только данные, которые действительно меняют план.

## Последовательность решения

1. Проверить согласованность класса, предмета, темы и цели обучения.
2. При необходимости разобрать цель по `learning-objective-analysis.md`.
3. Определить достижимую часть цели на урок без изменения официальной формулировки.
4. Сначала определить наблюдаемое доказательство обучения, затем критерий качества.
5. Спроектировать задания, которые поэтапно приводят к этому доказательству.
6. Определить основную педагогическую задачу и выбрать одну основную модель по `methodology-router.md`.
7. Запланировать точки проверки понимания и решения учителя по каждому типу ответа.
8. Устранить не относящиеся к цели барьеры и спланировать поддержку без необоснованного снижения цели.
9. Проверить реальность времени, ресурсов и переходов между действиями.
10. Завершить урок индивидуальным доказательством достижения каждой цели и определить следующий педагогический шаг.
11. По `teacher-methodological-guidance.md` перевести внутреннюю логику проектирования в понятное учителю объяснение: основная идея, границы содержания, связь действий и доказательства, решение при ошибке, поддержка, перенос и профессиональный вопрос. Не копировать этапы КСП и не выдавать внутренний аудит за методическое руководство.

Обязательная связь:

`цель обучения → цель урока → доказательство → критерий → задание → дескриптор → обратная связь → следующее решение`.

Структура урока может меняться по предмету, возрасту, цели и контексту. Не превращать последовательность решения в одинаковый сценарий этапов каждого урока.
