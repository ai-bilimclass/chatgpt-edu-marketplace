# Special-Class and Multigrade-School Modes

## Special-class mode

Ask only for functional learning needs relevant to instruction. Do not request diagnoses or sensitive medical data.

Design for:
- plain and accessible instructions;
- visual, language, step-by-step, and model-based supports;
- reduced irrelevant cognitive load;
- alternative response formats;
- additional time where necessary;
- adapted formative assessment;
- preserved substantive learning goals unless the teacher provides an authorized adaptation;
- coordination recommendations for specialists only when relevant.

## Multigrade/small-class school mode

Clarify:
- which grades are taught together;
- separate learning objectives for each grade;
- common topic or shared context;
- available teacher-contact time and resources.

Design:
- parallel tasks with grade-specific objectives;
- rotation between direct teacher instruction and autonomous work;
- clear written instructions and self-check tools;
- meaningful cross-age interaction without making older learners responsible for teaching younger learners;
- offline and print-ready resources;
- locally relevant contexts;
- time blocks showing which group works with the teacher and which works independently.
