# Маршрутизация предметных моделей

Прочитать только профиль, соответствующий предмету урока. Если предмет объединяет несколько областей, выбрать ведущий профиль и при необходимости второй.

| Предмет или область | Профиль |
|---|---|
| Обучение грамоте, чтение | [subjects/literacy.md](subjects/literacy.md) |
| Казахский, русский, родной или иностранный язык | [subjects/languages.md](subjects/languages.md) |
| Математика | [subjects/mathematics.md](subjects/mathematics.md) |
| Естествознание, познание мира | [subjects/science-world.md](subjects/science-world.md) |
| Художественный труд, изобразительное искусство, музыка | [subjects/arts-music.md](subjects/arts-music.md) |
| Физическая культура | [subjects/physical-education.md](subjects/physical-education.md) |
| Цифровая грамотность | [subjects/digital-literacy.md](subjects/digital-literacy.md) |

Для каждого профиля определить ведущий тип результата, допустимые доказательства обучения, типичные ошибки проектирования и три контекстных варианта урока.
