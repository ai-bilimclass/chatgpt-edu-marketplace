# Чек-лист качества

Перед выдачей подтвердить каждый пункт.

## Достоверность

- [ ] Код и формулировка цели перенесены без молчаливого исправления.
- [ ] Источник цели назван корректно.
- [ ] Нормативные и методические поля не смешаны.
- [ ] При юридически значимом запросе проверена действующая редакция.

## Согласованность

- [ ] Матрица замкнута для каждой цели.
- [ ] Цели урока наблюдаемы.
- [ ] Критерии отделены от дескрипторов.
- [ ] Все основные задания имеют продукт, критерий и обратную связь.
- [ ] Итог проверяет достижение каждой цели.

## Проведение урока

- [ ] Инструкции можно дать ученикам без додумывания.
- [ ] Приложены необходимые материалы, ответы или эталоны.
- [ ] Сумма времени точно равна длительности урока.
- [ ] Нагрузка и смена деятельности соответствуют возрасту.
- [ ] Адаптации конкретны и не содержат диагнозов.
- [ ] Цифровые ресурсы имеют офлайн-альтернативу, когда она нужна.

## Документ

- [ ] При отсутствии пользовательского шаблона использована общая языковая форма из `secondary/assets`, без перестройки для начальной школы.
- [ ] Названия и порядок полей, объединения ячеек и геометрия совпадают с формой 5–11 классов.
- [ ] Таблица хода урока содержит пять колонок в общем порядке: этап/время, педагог, ученик, оценивание, ресурсы.
- [ ] Цели урока и критерии оформлены отдельными настоящими маркерами Word.
- [ ] В казахском КСП раздел после основной формы называется «Әдістемелік қосымша», а заголовок «САБАҚ МАТЕРИАЛДАРЫ» отсутствует.
- [ ] После поля «Бағалау критерийлері» отсутствует пояснение `Ескерту: «Бағалау критерийлері» — әдістемелік қосымша ...`.
- [ ] В методическом приложении отдельным блоком показаны знания и навыки, выведенные из точной цели и темы, с наблюдаемым доказательством.
- [ ] Применение выбранной методической карточки описано через конкретный механизм урока, а не только названо.
- [ ] Внутренний аудит не показан в DOCX; приложение завершается фиксированным профессиональным уведомлением на языке документа.
- [ ] Автоматический аудит не содержит ошибок.
- [ ] Все предупреждения аудита рассмотрены вручную.
- [ ] Отрендерена и просмотрена каждая страница.
- [ ] Нет обрезанного текста, пустых страниц и плохих разрывов.
- [ ] DOCX остаётся полностью редактируемым.
