# Матрица согласованности

Заполнять внутренне до генерации DOCX. Создавать отдельную строку для каждой цели обучения. Не включать матрицу в документ без просьбы пользователя.

| Поле | Контрольный вопрос | Недопустимый разрыв |
|---|---|---|
| Цель обучения | Код и официальная формулировка сохранены? | Цель исправлена или дополнена без подтверждения |
| Цель урока | Какой наблюдаемый результат достижим за урок? | Описана деятельность учителя или слишком широкий результат |
| Критерий | Какой признак доказывает достижение цели? | Критерий не измеряет цель |
| Задание | Как ученик создаст наблюдаемое доказательство? | Активность есть, проверяемого продукта нет |
| Дескриптор | Какие конкретные действия или признаки проверяются? | Повтор инструкции вместо признака успеха |
| Обратная связь | Что сообщается ученику относительно критерия? | Общая похвала без корректирующей информации |
| Итоговая проверка | Как в конце подтверждается достижение цели? | Проверяется только настроение или участие |

## Правила замыкания

1. Каждая цель урока восходит к указанной цели обучения.
2. Каждая цель урока имеет хотя бы один критерий.
3. Каждый критерий проверяется хотя бы одним основным заданием.
4. Каждый основной продукт имеет дескриптор или эталон ответа.
5. Итоговая проверка охватывает все цели урока.
6. Если цель обучения охватывается только частично, прямо указать границы урока и не изменять официальный текст цели.

Любую незамкнутую строку исправить до создания DOCX.
