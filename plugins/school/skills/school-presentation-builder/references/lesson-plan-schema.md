# Формат `lesson-plan.json`

Сохранить только обязательные элементы КСП/ҚМЖ:

```json
{
  "topic": "Точная тема урока",
  "objectives": ["Точная формулировка цели 1"],
  "assessment_criteria": ["Критерий 1"],
  "required_tasks": ["Краткое уникальное название или ключевая фраза задания"],
  "assessment": ["Дескриптор или способ формативного оценивания"],
  "homework": ["Домашнее задание"],
  "duration_minutes": 40,
  "methodology": {
    "core_method": "Подтверждённый основной метод",
    "supporting_method": "",
    "specialized_method": "",
    "active_learning_methods": [],
    "student_actions": [],
    "learning_evidence": [],
    "formative_decision_points": [],
    "next_teacher_actions": [],
    "differentiation_and_accessibility": []
  }
}
```

Не перефразировать `topic` и `objectives`. Для длинного задания сохранять уникальные
ключевые слова, которые действительно присутствуют на слайде или в заметках.

При работе в том же чате разрешено получить эти поля из полного подтверждённого `lesson_plan_handoff` по [общему контракту](../../../references/lesson-plan-handoff.md). Для совместимости при чтении старого плана поле `success_criteria` можно принять как входное, но во внутренней карте и новых файлах использовать `assessment_criteria`.

Если в handoff есть `methodology`, сохранить блок без повторного выбора основной методики и использовать его для последовательности слайдов, действий учеников, заметок, доказательств и формативных решений. Если блок отсутствует в прикреплённом плане, поле можно опустить; не восстанавливать методику по названию темы.
