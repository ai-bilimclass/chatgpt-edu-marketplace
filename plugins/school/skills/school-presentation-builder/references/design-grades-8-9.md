# Дизайн для 8–9 классов

- Балансировать текст, данные и визуалы; использовать 3–5 блоков при ясной иерархии.
- Ориентироваться на 40–70 слов основного текста на слайде.
- Поддерживать сравнение, анализ источников, аргументацию и самостоятельный вывод.
- Не перегружать один слайд одновременно текстом, таблицей и большим изображением.
- Использовать современную, но не UI-подобную композицию.

| Роль | Целевой размер |
|---|---:|
| Заголовок слайда | 35–38 pt |
| Ключевая фраза/вопрос | 26–32 pt |
| Основной текст/инструкция | 22–28 pt |
| Таблица/диаграмма | 18–22 pt |
| Подпись | 17–20 pt |
| Источник | 14–17 pt |

Дифференциацию показывать через опоры и глубину рассуждения, не через ярлыки уровня.
