## 1. Принципы

- До создания нового PPTX показать учителю рекомендуемую палитру и структуру.
  Учитель может принять их, изменить отдельные решения или предоставить шаблон.
- Предлагать конкретный вариант, а не перекладывать разработку дизайна на учителя.
- Зафиксированный выбор учителя имеет приоритет; корректировать его только при
  риске читаемости, контраста, доступности или технической несовместимости и
  обязательно объяснять предлагаемую замену.
- Фон каждого слайда всегда белый `#FFFFFF`. Это базовая неизменяемая основа
  нового школьного PPTX, если учитель прямо не предоставил другой шаблон.
- Цветные палитры использовать только для текста заголовка, тонких линий,
  отдельных учебных моделей, небольших акцентных областей и выделения действия.
- Не заливать цветом весь слайд и не использовать большую цветную подложку как фон.
- Не использовать ою, национальный орнамент или крупный декоративный узор в фоне.
  Сохранять ранее выбранную чистую белую основу без фонового орнамента.
- Светлый оттенок палитры разрешён только в локальном блоке, занимающем не более
  трети площади слайда. Основное поле вокруг него остаётся белым.
- Проектировать слайд вокруг одной учебной функции и одного визуального фокуса.
- Подчинять оформление учебной цели; не использовать декор без учебной функции.
- Сохранять единую палитру, сетку, типографику и стиль визуалов.
- Писать видимый текст для ученика, а сценарий, время и ключи — в заметках.
- Не передавать смысл только цветом; дублировать подписью, формой или положением.
- Проверять слайды в размере школьного проектора.
- Не использовать цвет как единственный способ ответа, различения категорий или
  передачи правильности; добавлять слово, символ, контур или положение.
- Не помещать критически важную инструкцию только в изображение. Значимый текст
  должен оставаться редактируемым и доступным для чтения.

## 2. Палитры

Выбрать одну палитру. Белый `#FFFFFF` — обязательный фон, графитовый `#263238` —
основной нейтральный текст. Не использовать более одного яркого акцента на слайде.

| Палитра | Тёмный | Основной/акцент | Светлый фон | Предпочтительные предметы |
|---|---|---|---|---|
| Академический синий | `#12355B` | `#2F80ED`, `#F2C94C` | `#EAF3FB` | математика, науки, языки |
| Морская бирюза и тёплый жёлтый | `#0F5B66` | `#138A98`, `#F4B942` | `#EEF8F8` | биология, естествознание, география, экология |
| Индиго и коралл | `#3730A3` | `#6366F1`, `#E76F51` | `#F3F4FF` | языки, информатика, дискуссия |
| Терракота и тёмно-синий | `#8A3F2D` | `#2C5F73` | `#F8F5F2` | история, литература, право, искусство |

Пользовательский шаблон имеет приоритет над белым фоном только при его явной
загрузке или прямом требовании учителя. Не использовать жёлтый, терракотовый или
коралловый для длинного текста.

## 3. Типографика и единицы

- Использовать точное семейство `Arial` для всего видимого текста и заметок.
- Явно задавать Arial новым элементам; не полагаться только на тему.
- Не уменьшать размер ради лишнего текста: сокращать или менять макет.
- Не допускать переноса однострочного заголовка на две строки.
- Использовать полужирное начертание для опор, не для целых абзацев.

Artifact Tool использует пиксели для геометрии. Для текста использовать
`fontSizePt`. Если конкретный интерфейс принимает только `fontSize`, считать его
пикселями и переводить явно: `px = pt × 96 / 72`; `1 pt ≈ 1,333 px`.

Минимумы без пользовательского шаблона:

| Роль | Минимум |
|---|---:|
| Заголовок презентации | 50 pt |
| Заголовок слайда | 35 pt |
| Подзаголовок/опорный блок | 24 pt |
| Основной текст | возрастной файл, но не ниже 16 pt |
| Источник/служебный текст | 13 pt |

## 4. Контраст и композиция

- Контраст основного текста — не ниже 4,5:1; крупного — не ниже 3:1.
- Использовать формат 16:9 и безопасные поля не менее 5%, если шаблон не требует иного.
- Применять 12-колоночную сетку или простые доли 1/2, 1/3–2/3, 2/3–1/3.
- Сохранять одинаковое положение заголовков и повторяемые отступы.
- Выравнивать основной текст по левому краю; центрировать только короткие фразы.
- Избегать UI-подобных сеток карточек, кнопок, вкладок и «дашбордного» вида.
- Не размещать текст на неоднородном изображении без контрастной подложки.

## 5. Текст, изображения и данные

- Ограничивать обычный список 3–5 пунктами по 1–2 строки.
- Разбивать длинное задание на шаги с глаголами действия.
- Не дублировать слайд дословно в заметках.
- Сохранять пропорции изображений, осмысленно кадрировать, не использовать водяные знаки.
- Подписи делать отдельными редактируемыми элементами.
- Не использовать изображения только для заполнения пустоты.
- Таблицы применять для точного сопоставления; не помещать абзацы в ячейки.
- Схемы применять для этапов, иерархий и причинности; ограничивать число узлов.
- Диаграммы выбирать по вопросу: столбцы — сравнение, линии — динамика; не использовать 3D.
- Подписывать оси, единицы, период и источник данных.
- Для внешних фактов и визуалов добавлять прямой источник в `[Sources]` заметок.
- Для сложной схемы или изображения добавлять в заметки краткое текстовое описание,
  достаточное учителю для устного сопровождения учащихся с нарушением зрения.

## 6. Визуальная проверка

Для каждого отрендерленного слайда проверить:

- Arial, размер, иерархию и отсутствие неожиданного переноса;
- отсутствие обрезания, переполнения и наложений;
- читаемость с проектора, контраст и смысл без зависимости только от цвета;
- сетку, равные поля, один фокус и отсутствие случайных пустот;
- пропорции, резкость и кадрирование изображений;
- точность таблиц, схем и диаграмм;
- наличие источников и редактируемость элементов.

Контактный лист использовать для проверки последовательности и разнообразия
силуэтов, но не вместо просмотра каждого слайда в полном размере.
