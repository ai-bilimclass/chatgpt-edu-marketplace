# ҚМЖ/КСП handoff для производных материалов

Рабочий, практический или лабораторный лист и новая презентация создаются только на основе готового ҚМЖ/КСП/Lesson Plan.

Допустимы два источника:

1. прикреплённый учителем файл плана урока в читаемом формате;
2. последняя успешно созданная и проверенная плагином версия плана урока в текущем чате, автоматически переданная как `lesson_plan_handoff`.

Само наличие темы, цели, КТП или краткого описания урока не заменяет готовый план. План из другого чата повторно не восстанавливать по памяти: попросить прикрепить файл.

## Контракт handoff

Сразу после успешного создания, проверки и передачи плана урока автоматически сохранить внутренний пакет, не требуя фразы `ҚМЖ-ны қабылдаймын`, `КСП принимаю`, `I accept the lesson plan` или иного отдельного подтверждения:

```yaml
lesson_plan_handoff:
  source: "same_chat_generated_lesson_plan"
  ready_for_derivatives: true
  continuity_notice_shown: false
  artifact_path: ""
  grade: ""
  subject: ""
  instruction_language: ""
  document_language: ""
  topic: ""
  duration_minutes: ""
  learning_objectives: []
  assessment_criteria: []
  lesson_stages: []
  required_tasks: []
  expected_answers: []
  formative_assessment: []
  support_and_extension: []
  homework: ""
  sources: []
  methodology:
    pedagogical_task: ""
    learning_stage: ""
    learner_difficulty: ""
    core_method: ""
    supporting_method: ""
    specialized_method: ""
    active_learning_methods: []
    student_actions: []
    learning_evidence: []
    formative_decision_points: []
    next_teacher_actions: []
    differentiation_and_accessibility: []
```

`ready_for_derivatives: true` устанавливать только после успешного завершения содержательной, структурной и визуальной проверки и передачи готового файла учителю. Не устанавливать для черновика, ошибки, незавершённой генерации или файла, не прошедшего обязательную проверку. Это состояние означает готовность использовать текущую версию как основу производных материалов, а не формальное утверждение документа учителем или школой.

Производный навык принимает пакет без повторной загрузки файла и без подтверждающей фразы, если он относится к текущему чату, полный для запрошенного продукта и не существует более новой или противоречащей версии плана. Если учитель изменил план или указал использовать другой документ, обновить пакет по новой версии. В другом чате попросить прикрепить файл.

Если в текущем чате есть несколько готовых планов разных классов, предметов или тем и выбор основы неоднозначен, до разработки задать один короткий вопрос, какой именно план использовать. Не выбирать план только по давности, если новый запрос может относиться к другому классу или предмету.

После приёма пакета не спрашивать повторно класс, предмет, язык, тему, продолжительность и точные цели. Одним сообщением запросить только параметры, специфичные для нового материала.

Блок `methodology` формирует только `school-lesson-planner` по [центральному методическому маршрутизатору](../skills/school-lesson-planner/references/methodology-router.md). Производный навык применяет подтверждённое решение и не выбирает другую основную методику. Пустой `supporting_method` или `specialized_method` допустим. Если прикреплённый план не содержит явной методической модели, производный навык не должен придумывать её: использовать только зафиксированные этапы, задания, критерии и доказательства.

## Одноразовое уведомление о продолжении работы в одном чате

После первого успешно созданного ҚМЖ/КСП/Lesson Plan в текущем чате вывести одно локализованное уведомление. Затем установить `continuity_notice_shown: true` и не повторять полный текст в этом чате. Уведомление носит информационный характер: не просить согласия, подтверждения или специальной фразы.

- қазақша: `Ескерту: бір сынып пен пәнге арналған өзара байланысты оқу материалдарын осы чатта жалғастырып жасаған дұрыс. Осылайша плагин бұрын жасалған ҚМЖ, тақырып, оқу мақсаттары және сынып туралы мәліметтерді келесі материалдарға қолдана алады. Жаңа чатта жұмыс бастасаңыз, қажетті ҚМЖ/КСП файлын қайта тіркеңіз.`
- русский: `Примечание: взаимосвязанные учебные материалы для одного класса и предмета рекомендуется создавать в одном чате. Так плагин сможет использовать ранее созданный поурочный план, тему, цели обучения и сведения о классе. При переходе в новый чат прикрепите нужный файл ҚМЖ/КСП повторно.`
- English: `Note: it is recommended to create related learning materials for the same class and subject in one chat. This allows the plugin to use the previously created lesson plan, topic, learning objectives, and class information. If you start a new chat, attach the relevant lesson plan again.`

Перед созданием каждого производного материала в текущем чате вывести только короткое локализованное примечание: `Материал будет подготовлен на основе последнего ҚМЖ/КСП в этом чате` либо его казахский или английский эквивалент. Если учитель указал другой план, назвать выбранный план вместо последнего. Не утверждать, что план сохранён в постоянной памяти.

После уведомления сразу показать обычный выбор следующего материала. Уведомление не является вопросом и не блокирует дальнейшую работу.
